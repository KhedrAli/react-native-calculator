# 📱 Secure React Native Calculator

A secure, modular, and lightweight calculator built with React Native, emphasizing defensive programming and zero external dependencies (excluding core APIs).

## 🚀 Key Features
- **Secure Calculation Logic:** Strictly avoids vulnerable `eval()` execution by utilizing sandboxed computation patterns with robust input sanitization.
- **Defensive Programming:** Built-in edge-case management, division-by-zero checks, and error boundaries to prevent app crashes.
- **Dynamic Theming:** Seamless Dark/Light mode switching powered by optimized state logic.
- **Localization Support:** Full RTL (Right-to-Left) and LTR layout adaptation.
- **Clean Architecture:** Modular component structure following industry best practices.

## 🛠️ Tech Stack
- **Framework:** React Native / Expo
- **Language:** TypeScript / JavaScript
- **Styling:** StyleSheet (Native UI primitives)
